# Week 2 - Search and optimization

Central question: **How do we find a good solution when checking everything is expensive?**

Students compare exhaustive search with gradient ascent on the same visible objective function. The deliberate failure case is starting gradient ascent in different regions and reaching different optima.

Key terms: search space, candidate solution, objective function, gradient, step size, local optimum, global optimum, exploration and exploitation.
