# Week 3 - k-nearest neighbours

Central question: **Can nearby examples vote on a prediction?**

Students change `k`, observe the decision boundary and compare training with test accuracy. The deliberate failure cases are `k=1`, an excessively large `k`, and unscaled features.

Key terms: feature, label, distance, neighbour, classification, accuracy, confusion matrix and generalization.
