# Week 1 - From numbers to a decision boundary

## The 90-minute plan

| Time | Activity |
|---|---|
| 0-5 min | Welcome, repository and expectations |
| 5-15 min | Menti screens 1-4 |
| 15-30 min | Vectors, matrices and shapes in the notebook |
| 30-43 min | Dot product and score |
| 43-45 min | Menti screen 5 |
| 45-55 min | Break |
| 55-68 min | Plot the decision boundary |
| 68-78 min | Pair experiment: change `w` and `b` |
| 78-85 min | XOR failure case |
| 85-90 min | Menti screens 7-8 and exit |

## Learning goals

Students should be able to:

1. Interpret one example as a feature vector and several examples as a matrix.
2. Compute and interpret `w^T x + b`.
3. Explain why `w^T x + b = 0` is a linear decision boundary.

For the first session, spend at most three hours: build the Menti, rehearse the notebook once, and test the student links. Later sessions should normally fit within two hours of preparation.
