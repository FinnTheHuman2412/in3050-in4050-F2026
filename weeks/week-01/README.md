# Week 1 — Vectors, matrices and decision boundaries

## Learning goals

After the session, students should be able to:

- interpret vectors as feature descriptions of individual examples;
- interpret matrices as collections of examples or transformations;
- compute and explain a dot product;
- explain how `w · x + b = 0` defines a linear decision boundary;
- distinguish classification from regression.

## Main misconception

A decision boundary is not a line that the data automatically reveals. It is determined by model parameters, and different parameters produce different boundaries.

## Before class

Students only need basic Python familiarity. NumPy syntax is introduced inside the notebook.
