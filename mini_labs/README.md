# Mini-labs

Short, reusable experiments that fit into 10-25 minutes of a group session.

Each mini-lab follows the same rhythm:

1. Predict what will happen.
2. Run the smallest useful experiment.
3. Change one parameter.
4. Explain why the output changed.
5. Connect the observation to an exam concept.

Start with [decision-boundary-playground.ipynb](decision-boundary-playground.ipynb).
