## Problems with Anaconda?
1) Use an IFI machine where the Python setup should already be prepared. It is available here: https://www.uio.no/tjenester/it/maskin/programvare/programkiosk/hjelp/vmware.html

or

2) Try to avoid Anaconda and use another tool to manage Python installation, such as venv: https://packaging.python.org/en/latest/guides/installing-using-pip-and-virtual-environments/
