# Course map

The repository follows the conceptual progression visible across the course material and earlier group-teaching repositories. Each week has one central question, one visual failure case, and one exam connection.

| Week | Central question | Visual or experiment | Key terms |
|---|---|---|---|
| 01 | How do numbers become a decision? | Move a linear boundary by changing `w` and `b` | vector, matrix, feature, dot product, boundary |
| 02 | How do we search when checking everything is expensive? | Compare exhaustive search and gradient ascent | search space, objective, exploration, exploitation |
| 03 | Can nearby examples vote on a prediction? | Change `k` and watch the kNN boundary | distance, neighbour, classification, generalization |
| 04 | Can a machine learn a straight boundary? | Trace perceptron weight updates | perceptron, linear separability, bias |
| 05 | How can populations search? | Evolve routes through European cities | genome, fitness, mutation, crossover, selection |
| 06 | Why does evolution need diversity? | Compare mutation rates and convergence | diversity, premature convergence, elitism |
| 07 | How does a score become a probability? | Compare linear and logistic regression | sigmoid, likelihood, loss, threshold |
| 08 | How can layers bend a boundary? | Learn XOR or moons with an MLP | hidden layer, activation, backpropagation |
| 09 | How can we discover structure without labels? | Cluster the same data with different `k` | clustering, centroid, inertia |
| 10 | How do models learn from images? | Inspect convolutional feature maps | convolution, kernel, pooling, representation |
| 11 | What should students recognize on the exam? | Diagnose deliberately misleading alternatives | model choice, evaluation, reasoning |

## Notebook rule

Every main notebook should contain:

1. One concrete story.
2. Three learning goals.
3. A prediction before the first result.
4. A small implementation or experiment.
5. One deliberate failure case.
6. One IN4050 extension.
7. An exit ticket with define, apply and diagnose questions.

## Public-repository boundary

Publish original teaching notebooks, small licensed datasets, instructions and unanswered exercises. Keep mandatory-assignment solutions, exam solutions, student work and private TA notes outside the public branch.
