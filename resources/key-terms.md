# Key terms

## Week 1

- **Feature:** A measurable input used by a model.
- **Feature vector:** One example represented as an ordered list of feature values.
- **Dataset matrix:** A table in which rows are examples and columns are features.
- **Weight vector:** Parameters that determine how strongly each feature affects a linear model.
- **Bias:** A constant that shifts a decision boundary without rotating it.
- **Dot product:** Weighted sum of corresponding vector components.
- **Decision score:** For a linear classifier, typically `w · x + b`.
- **Decision boundary:** Inputs for which the classifier is exactly undecided; `w · x + b = 0`.
- **Classification:** Predicting a discrete category.
- **Regression:** Predicting a continuous number.
