# Session template

Use this checklist when creating a new weekly package.

```text
weeks/week-NN/
  README.md
  NN-topic.ipynb

menti/
  week-NN.md
```

## README

- Central question
- 90-minute schedule
- Three learning goals
- Links to notebook and Menti
- Optional section to skip

## Notebook

1. Story and learning goals
2. Imports
3. Small visible dataset or problem
4. Prediction prompt
5. Simplest working method
6. Student experiment
7. Deliberate failure
8. IN4050 extension
9. Exit ticket

## Menti

- One confidence or background question
- Two conceptual predictions
- One misconception diagnosis
- One open exit response
