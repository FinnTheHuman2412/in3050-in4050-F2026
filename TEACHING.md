# Teaching guide

## The 105-minute group-session rhythm

| Time | Activity | Goal |
|---|---|---|
| 0–10 min | Retrieval warm-up | Activate prior knowledge without notes |
| 10–25 min | Build the mental model | Explain the smallest useful idea |
| 25–50 min | Guided notebook experiment | Make the idea visible |
| 50–60 min | Break | Reset attention |
| 60–85 min | Student problem solving | Move from watching to doing |
| 85–100 min | Exam-style transfer | Recognize the idea in unfamiliar wording |
| 100–105 min | Exit ticket | Reveal what needs repetition |

## Weekly preparation checklist

- Identify three concepts students must explain after the session.
- Select one misconception worth exposing.
- Build one plot or experiment whose output changes visibly.
- Include at least one prediction before execution.
- Add one basic task and one IN4050 extension.
- Test the notebook from a clean environment.
- Ensure all cells run top-to-bottom.
- Prepare one optional section to skip if time runs short.

## Notebook conventions

- Use `🧠 Predict` before revealing an output.
- Use `✍️ Explain` for pair discussion or written answers.
- Use `🔬 Experiment` when students change code.
- Use `🎓 IN4050 extension` for deeper mathematical or implementation work.
- End with three questions: define, apply, diagnose.

## Publishing workflow

1. Develop in a private TA workspace.
2. Remove solutions and hidden notes.
3. Restart the kernel and run all cells.
4. Commit with a descriptive message such as `Add week 03 heuristic-search lab`.
5. Publish solutions only when course policy permits it.
